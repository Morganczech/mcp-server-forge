# Agent instructions

These instructions apply to the entire repository.

1. Before starting work, read `README.md`, `ROADMAP.md`, and `TASKS.md`.
2. Do not change files outside the scope of the assigned task.
3. Do not hard-code project data, server definitions, or template content in
   TypeScript.
4. The server configuration is the single source of truth.
5. Do not edit generated files manually. Change their configuration or template
   and regenerate them instead.
6. After changes, run `pnpm lint`, `pnpm typecheck`, and `pnpm test`.
7. Never run `git push` automatically. Push only after an explicit user request.
8. Do not commit unless explicitly requested.
